# portfolio-v2

## What It Is

A professional developer portfolio showcasing full-stack skills through practical implementation. This isn't just a static website—it's a live demonstration of modern web development expertise.

## What It Solves

Traditional portfolios either lack technical depth or demonstrate poor code quality. This portfolio:

- ✅ Shows **React 19 + TypeScript** expertise
- ✅ Implements **performance optimizations** (intersection observers, lazy loading)
- ✅ Follows **industry best practices** (accessibility, SEO, maintainability)
- ✅ Demonstrates **full-stack capabilities** through the site itself

## Key Features

**Navigation & UX:**

- Sticky header with scroll-spy active links
- Keyboard-accessible skip links
- Theme toggle (light/dark mode)
- Scroll-to-top button with intersection observer

**Visual Effects:**

- Reveal animations on scroll
- Typewriter effect in hero section
- Skill level indicators (3-category grid)
- Responsive project showcase

**Professional Tools:**

- Native form validation with mailto
- WCAG 2.1 AA compliance
- Performance optimized (no scroll listeners)
- Comprehensive test coverage

## Technical Stack

- **Frontend:** React 19 + TypeScript, Vite, CSS Modules
- **Performance:** IntersectionObserver, lazy loading, CSS animations
- **Quality:** Vitest, ESLint, Prettier, accessibility-focused
- **Architecture:** Component-based, data-first, pure utilities

## What It Shows

- **About**: Professional background and skills
- **Skills**: Frontend, backend, and tools categories
- **Projects**: Live project showcases with tech stacks
- **Contact**: Professional form and social links

Built to demonstrate current web development best practices and real-world problem-solving capabilities.
